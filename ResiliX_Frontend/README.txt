ResiliX — Complete Updated Frontend

Files:
- index.html
- styles.css
- app.js

Installation:
1. Extract this ZIP.
2. Copy the three files into your existing ResiliX_Frontend folder, replacing the previous versions.
3. Start the backend from ResiliX_Reliability_Backend:
   .\ResiliX.exe api
4. Open index.html using VS Code Live Server.
5. Hard-refresh the browser with Ctrl+F5.

The frontend expects the API at http://localhost:8080/api.
